# Посмотреть идеи

Читает `IDEAS.md` в корне проекта и показывает список. Отсюда же меняется
статус. **Ничего не реализуй** — из просмотра списка нельзя случайно начать
работу; если владелец захочет что-то сделать, он скажет об этом отдельно.

## Как показывать

Сгруппируй по статусу и пронумеруй сквозной нумерацией — по номерам владелец
потом и говорит («третью подробно», «пятую отклонить»).

```
НОВЫЕ
 1. Название — выжимка в одну строку (08.09.2026)
 2. …

СДЕЛАНЫ
 7. Название (1.38)

ОТКЛОНЕНЫ
 9. Название — причина в несколько слов
```

* Порядок внутри группы — как в файле, новые сверху.
* **Выжимка в одну строку**, а не текст записи целиком: список должен читаться
  целиком с одного экрана. Полный текст показывается по просьбе («третью
  подробно»).
* Сделанные и отклонённые показывай **после** новых и только названиями. Их
  ценность в том, чтобы не предлагать то же самое дважды, а не в подробностях.
* Идей нет вовсе — так и скажи одной строкой, ничего не выдумывай.

## Как менять статус

Владелец говорит «вторую сделали», «четвёртую отклоняем, слишком дорого» —
правь `IDEAS.md`:

* меняй строку статуса: `новая` → `сделана` или `отклонена`;
* у сделанной допиши версию, в которой это вышло, если знаешь: `сделана` ·
  08.09.2026 · 1.38;
* у отклонённой **обязательно** запиши причину отдельной строкой
  `**Почему нет:** …`. Без причины та же идея вернётся через месяц, и разговор
  начнётся заново.

Запись при этом не удаляй никогда — ни сделанную, ни отклонённую. Список идей
ценен именно историей решений.

## Идеи с телефона

В приложении есть кнопка-лампочка, и оттуда идея уезжает не в этот файл, а в
issues с меткой «идея». Это разные входы, а не дублирование: под рукой телефон —
пишешь в приложении, сидишь за кодом — в файл.

Когда владелец просит показать идеи, загляни и туда:

```
gh issue list --label "идея" --state open --limit 100 --json number,title,body
```

Показывай их в том же списке, пометив источником, — но **в `IDEAS.md` не
переписывай**: две записи об одном превратятся в две задачи. Закрывать такие
идеи надо там же, где они лежат, через `gh issue close`.

## После правки

Закоммить только `IDEAS.md`, сообщением вида `Идея сделана: <название>` или
`Идея отклонена: <название>`. Просмотр без правок ничего не коммитит.
