# Лицензии скачанного материала

Файлы в этом каталоге — чужие данные под свободными лицензиями. Пока они лежат
только в репозитории, обязательств почти нет; **как только строка из них попадёт
в `assets/lessons` и уедет в APK, требуется атрибуция**.

## `sr_50k.txt`, `frequency-gap.tsv`

Частотный список сербского по корпусу субтитров OpenSubtitles 2018.

* Источник: <https://github.com/hermitdave/FrequencyWords>, `content/2018/sr/sr_50k.txt`
* Лицензия: **CC BY-SA 4.0**
* Скачано: 06.09.2026

`frequency-gap.tsv` — производное (те же слова, отобранные по незнанию курсом),
значит под той же лицензией.

Использование в приложении: список нужен для **отбора** слов, сами слова языка
никому не принадлежат. Если список не воспроизводится как список, обязательств
не возникает.

## `tatoeba-sr-ru.jsonl`, `tatoeba-sr-ru-short-lat.tsv`

Пары предложений сербский↔русский из проекта Tatoeba.

* Источник: <https://downloads.tatoeba.org/exports/per_language/srp/>
  (`srp_sentences.tsv.bz2`, `srp-rus_links.tsv.bz2`, плюс `rus_sentences.tsv.bz2`)
* Лицензия: **CC BY 2.0 FR**, часть предложений дополнительно CC0 1.0
* Скачано: 06.09.2026, id предложений сохранены в поле `sr_id` / `ru_id`

Использование в приложении: **дословно перенесённая фраза требует ссылки на
Tatoeba**. Переписанная своими словами — нет. Id в файле оставлены как раз для
того, чтобы можно было отследить происхождение конкретной строки.

## `rjecnik-sr-ru.tsv`

Сербские статьи русского Викисловаря, выгрузка kaikki.org, заголовки
транслитерированы в латиницу.

* Источник: <https://kaikki.org/ruwiktionary/> → раздел «Сербский»
* Первоисточник: ru.wiktionary.org
* Лицензия: **CC BY-SA 4.0** и GFDL (двойное лицензирование Викисловаря)
* Скачано: 06.09.2026

Использование в приложении: толкования — авторский текст. Дословный перенос в
`glossary.json` тянет за собой **CC BY-SA**, то есть требует и ссылки, и
совместимой лицензии на производное. Наши подсказки короче («пляж (вин. п.)»),
и написать их своими словами по смыслу статьи проще, чем связываться с
share-alike.

## `wiktionary-stress.json`

Разметка ударений сербохорватских слов из английского Викисловаря: у каждого
слова словаря — все написания со знаками акцентов, как они стоят в шаблонах
`{{sh-noun|apotéka|f}}` и `{{sh-IPA|vòda}}`.

* Источник: <https://en.wiktionary.org/w/api.php>, раздел Serbo-Croatian
* Лицензия: **CC BY-SA 4.0** и GFDL (двойное лицензирование Викисловаря)
* Скачано: 09.09.2026, скриптом `tools/fetch_stress.py`

Использование в приложении: **это единственный чужой материал, который уехал в
APK как данные**. `assets/vocab/stress.json` — производное от этого файла: 405
строк «лемма → номер ударной буквы», без единого слова чужого текста. Голый
факт вроде «ударение в `apoteka` на третьей букве» авторским правом не
охраняется, но набор фактов, отобранный чужой работой, — материал спорный, и
спорить тут не о чем: ссылка стоит в приложении (настройки → «Источники») и
здесь, а сам файл лежит в репозитории под той же CC BY-SA.

Слова в один-два слога в производный файл не попадают вовсе — их ударение
считается по правилу, а правило чужой работой не является. Викисловарь для них
служил только проверкой.
