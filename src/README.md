# Crnogorski

Персональный тренажёр черногорского для одного пользователя. Русский → черногорский, только латиница, без геймификации.

## Сборка

1. Открой папку в Android Studio (Ladybug или новее).
2. Создай `local.properties` рядом с `settings.gradle.kts`:

```
sdk.dir=/путь/к/Android/sdk
ANTHROPIC_API_KEY=sk-ant-...
```

Ключ попадает в `BuildConfig` на этапе сборки и не хранится в git. Файл `.gitignore` уже его исключает.

3. `Run` на устройстве с Android 15 (`minSdk 35`, обратной совместимости нет).

## Что где лежит

| Путь | Назначение |
|---|---|
| `assets/lessons/` | Уроки в JSON, `index.json` — оглавление |
| `data/Model.kt` | Типы заданий |
| `data/LessonRepository.kt` | Чтение уроков, локальная сверка ответов |
| `net/HaikuChecker.kt` | Проверка свободных переводов через Claude Haiku |
| `srs/Scheduler.kt` | Интервальные повторы |
| `speech/Speech.kt` | Синтез и распознавание речи (`sr-RS`, латиница) |
| `ui/` | Compose-интерфейс |

## Проверка ответов

Задания делятся на две группы.

**Локально, без сети:** выбор варианта, сборка из слов, подстановка формы, аудирование, произношение. Сравнение строк с нормализацией регистра и пунктуации. Диакритика (č, ć, š, ž, đ) учитывается — кроме распознавания речи, где она теряется на стороне движка.

**Через Haiku:** свободные переводы в обе стороны. Модель получает задание, эталон и твой ответ, возвращает JSON с вердиктом и разбором ошибки. Эталон подан как один из допустимых вариантов, а не единственный, поэтому синонимы и другой порядок слов засчитываются.

Если в уроке есть свободные переводы, а сети нет, экран урока сразу говорит об этом и не даёт продолжить.

## Интервальные повторы

Каждое задание — карточка. Верный ответ двигает интервал по SM-2 (1 → 3 → интервал × лёгкость), ошибка сбрасывает счётчик и возвращает карточку через 10 минут. Блок «Повторение» на главном экране собирает всё, что подошло по сроку, из любых уроков.

## Добавление уроков

Положи новый файл в `assets/lessons/`, добавь строку в `index.json`, подними `versionCode`, собери APK. Прогресс в Room не пострадает: карточки привязаны к `exerciseId`.

**Важно:** `id` заданий должны быть уникальны по всему курсу и не меняться между версиями — иначе история повторений для них потеряется. Схема `l09e01`.

### Формат задания

```json
{ "type": "ru_to_me",   "id": "l09e01", "prompt": "Я иду домой.", "reference": "Idem kući.", "hint": "" }
{ "type": "me_to_ru",   "id": "l09e02", "prompt": "Idem kući.", "reference": "Я иду домой." }
{ "type": "choice",     "id": "l09e03", "prompt": "Дом", "options": ["kuća", "grad"], "answer": "kuća", "explanation": "" }
{ "type": "word_bank",  "id": "l09e04", "prompt": "Я иду домой.", "answer": "Idem kući", "bank": ["Idem", "kući", "kuća"] }
{ "type": "form",       "id": "l09e05", "prompt": "Ja ___ kući. (ići)", "answer": "idem", "explanation": "" }
{ "type": "listening",  "id": "l09e06", "audioText": "Idem kući", "translation": "Я иду домой" }
{ "type": "speaking",   "id": "l09e07", "phrase": "Idem kući", "translation": "Я иду домой" }
```

## Речь

Локали «черногорский» в Android нет, используется `sr-RS` с латиницей. Если аудирование молчит, поставь голос: Настройки → Система → Языки и ввод → Синтез речи → установить сербский. Распознавание требует Google-приложение и работает по сети.

Произношение оценивается по факту: если движок распознал нужную фразу, задание засчитано. Качество звучания не оценивается.
