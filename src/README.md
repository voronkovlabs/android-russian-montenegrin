# Crnogorski

Персональный тренажёр черногорского для одного пользователя. Русский → черногорский, только латиница.

## Сборка

1. Открой папку в Android Studio (Ladybug или новее).
2. Создай `local.properties` рядом с `settings.gradle.kts`:

```
sdk.dir=/путь/к/Android/sdk
GITHUB_TOKEN=github_pat_...
```

`GITHUB_TOKEN` нужен только отправке жалоб в issues; без него приложение работает, жалобы копятся в файле на телефоне. Файл `.gitignore` уже исключает `local.properties`.

**Ключ Anthropic в сборку не входит.** Свободные переводы проверяет Claude по ключу того, кто пользуется приложением: при первом запуске он спрашивается на весь экран и вводится руками. Заводится на console.anthropic.com, раздел API Keys.

3. `Run` на устройстве с Android 14 или новее (`minSdk 34`).

## Что где лежит

| Путь | Назначение |
|---|---|
| `assets/lessons/` | Уроки в JSON, `index.json` — оглавление |
| `data/Model.kt` | Типы заданий |
| `data/LessonRepository.kt` | Чтение уроков, локальная сверка ответов |
| `net/HaikuChecker.kt` | Проверка свободных переводов через Claude Haiku |
| `srs/Scheduler.kt` | Интервальные повторы |
| `speech/Speech.kt` | Синтез и распознавание речи (`sr-RS`, латиница) |
| `ui/` | Compose-интерфейс |

## Проверка ответов

Задания делятся на две группы.

**Локально, без сети:** выбор варианта, сборка из слов, подстановка формы, аудирование, произношение, повтор на слух, чтение вслух. Сравнение строк с нормализацией регистра и пунктуации. Диакритика (č, ć, š, ž, đ) учитывается — кроме распознавания речи, где она теряется на стороне движка.

**Через Haiku:** свободные переводы в обе стороны. Модель получает задание, эталон и твой ответ, возвращает JSON с вердиктом и разбором ошибки. Эталон подан как один из допустимых вариантов, а не единственный, поэтому синонимы и другой порядок слов засчитываются.

Если в уроке есть свободные переводы, а сети нет, экран урока сразу говорит об этом и не даёт продолжить.

## Интервальные повторы

Каждое задание — карточка. Верный ответ двигает интервал по SM-2 (1 → 3 → интервал × лёгкость), ошибка сбрасывает счётчик и возвращает карточку через 10 минут. Блок «Повторение» на главном экране собирает всё, что подошло по сроку, из любых уроков.

## Добавление уроков

Положи новый файл в `assets/lessons/`, добавь строку в `index.json`, подними `versionCode`, собери APK. Прогресс в Room не пострадает: карточки привязаны к `exerciseId`.

**Важно:** `id` заданий должны быть уникальны по всему курсу и не меняться между версиями — иначе история повторений для них потеряется. Схема `l09e01`.

Типов заданий одиннадцать, но в файлах уроков встречаются девять: `word`
(словарная карточка) и `match` (пары слов) собираются на лету из
`assets/vocab/words.json` и руками не пишутся.

### Формат задания

```json
{ "type": "ru_to_me",   "id": "l09e01", "prompt": "Я иду домой.", "reference": "Idem kući.", "hint": "" }
{ "type": "me_to_ru",   "id": "l09e02", "prompt": "Idem kući.", "reference": "Я иду домой." }
{ "type": "choice",     "id": "l09e03", "prompt": "Дом", "options": ["kuća", "grad"], "answer": "kuća", "explanation": "" }
{ "type": "word_bank",  "id": "l09e04", "prompt": "Я иду домой.", "answer": "Idem kući", "bank": ["Idem", "kući", "kuća"] }
// bank можно писать в любом порядке: на экране слова перемешиваются
{ "type": "form",       "id": "l09e05", "prompt": "Ja ___ kući. (ići)", "answer": "idem", "explanation": "" }
{ "type": "listening",  "id": "l09e06", "audioText": "Idem kući", "translation": "Я иду домой" }
{ "type": "speaking",   "id": "l09e07", "phrase": "Idem kući", "translation": "Я иду домой" }
{ "type": "repeat",     "id": "l09e08", "phrase": "Idem kući", "translation": "Я иду домой" }
{ "type": "reading",    "id": "l09e09", "text": "Idem kući. Sjutra idem na plažu.", "translation": "Я иду домой. Завтра иду на пляж." }
```

## Подсказки по словам

Знакомые слова в задании подчёркнуты; по нажатию под текстом появляется перевод. Словарь — `assets/glossary.json`, вида `{"me": {"plažu": "пляж (вин. п.)"}, "ru": {"пляж": "plaža"}}`. Ключ — словоформа в нижнем регистре ровно такая, как в задании. Новые уроки требуют и новых слов в словаре, иначе подсказок по ним не будет.

## Речь

Локали «черногорский» в Android нет, используется `sr-RS` с латиницей. Если аудирование молчит, поставь голос: Настройки → Система → Языки и ввод → Синтез речи → установить сербский. Распознавание требует Google-приложение и работает по сети.

Произношение оценивается по факту: если движок распознал нужную фразу, задание засчитано. Качество звучания не оценивается.

`repeat` — та же проверка, что у `speaking`, но текст на экране закрыт: фраза звучит сама, открыть текст можно кнопкой. После ответа он открывается сам.

Чтение вслух записывается по одному предложению: движок распознавания на длинной фразе просто отвечает «ничего не расслышал». Услышанное склеивается и сверяется мягко — доля слов текста, прозвучавших по порядку, порог 75%. Сорванное предложение перечитывается на месте.

В полях ввода есть микрофон — продиктовать ответ вместо набора. Язык распознавания и подсказка клавиатуре берутся из языка ответа: черногорский — `sr-RS` и `sr-Latn-RS`, русский — `ru-RU`. В аудировании микрофона нет намеренно: продиктовать услышанное значит поручить распознавателю ровно ту работу, ради которой задание и есть.
