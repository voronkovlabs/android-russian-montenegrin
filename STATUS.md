## Где остановились

**06.09.2026, метка `lessons-26`, версия 1.21.** Двадцать шесть уроков, 286 заданий,
551 слово в подсказках, три истории в трёх занятиях. Программа A1–A2 закрыта,
кроме условного наклонения.

У историй теперь три режима на одних и тех же текстах:

* **чтение вслух** — как было;
* **на слух** — текст закрыт прочерками, отрезок звучит сам и сам переходит
  в запись, повторить надо с голоса; проверка местная;
* **перевод вслух** — показан русский, сказать надо по-черногорски, проверяет
  Haiku (`checkSpoken`).

В двух последних после трёх неудач текст показывается, и отрезок доигрывается
как чтение. Прогресс у режимов раздельный (`story_progress` с составным ключом,
Room v3). На вкладке «Истории» три складные группы, все свёрнуты по умолчанию.
`Speaker.speak` научился сообщать о конце фразы — на слух микрофон включается
именно по нему.

Ни один вызов `checkSpoken` не проверен вживую — промпт написан, но не обкатан;
цена вопроса около 0,1 ¢ за отрезок. Режим «на слух» на устройстве тоже не
запускался: связка «синтез договорил → включился микрофон» проверяется только
руками.

Восемнадцать уроков (l09–l26) сделаны подряд **без единой проверки на устройстве**.
Проверены только сборка, целостность JSON, покрытие подсказками и язык — через
Haiku, тремя прогонами на 187 фраз, суммарно 3,3 цента. Как это ощущается в руках,
не знает никто.

Что делать дальше, зависит от проверки:

  числительные и даты, дальше уроки уровня 3 до сорока-шестидесяти;
* **не зашло по мелочи** — править точечно, метка не нужна;

Проверить в первую очередь: l09 (первый урок нового строя) и l21 (последняя
пачка), копию прогресса в папку, историю до конца — и отдельно два новых режима:

## Что уже решено и не обсуждается заново

| Решение | Почему |
|---|---|
| Android 14+ (`minSdk 34`) | Ниже не спускаемся: старых устройств у владельца нет, а Compose и java.time на 34 уже без оговорок |
| Девять типов заданий | Ввод текста в обе стороны, выбор, сборка, морфология, аудирование, произношение, повтор на слух, чтение вслух |
| Haiku только для свободных переводов | Остальное однозначно проверяется строкой; экономия вызовов и работа офлайн |
| Урок блокируется без сети | Выбор владельца: лучше не начать урок, чем не засчитать половину заданий |
| Произношение без оценки качества | Достаточно факта, что движок распознал фразу |
| Уроки в assets, не на сервере | Обновления приходят вместе с версией приложения |
| SM-2 вместо FSRS | Объём курса маленький, сложный алгоритм не окупается |
| Локаль `sr-RS` | Локали «черногорский» в Android нет |
| Диакритика значима при проверке | č/ć/š/ž/đ различают слова, привычка нужна с самого начала |
| Экавица засчитывается наравне с иекавицей | Хорошо говорить по-сербски — приемлемый исход; свободный материал весь сербский |
| Терпимость только к набранному, не к выбранному | В l06e07 выбор между sutra и sjutra — и есть задание |
| Жалобы в JSONL на устройстве | Пользователь один, сервер и токены не нужны; забирается `gradlew pullComplaints` по USB |
| Жалоба откатывает карточку SRS | Ответ на сломанное задание ничего не говорит о знаниях |
| Отчёт уходит через системный share | Telegram есть в шторке и так; бот потребовал бы токен в APK и сеть |
| «Очистить» архивирует, а не удаляет | Android не сообщает, дошла ли отправка — удаление по нажатию теряет данные молча |
| Жалоба не про задание — диалог, а не экран | Написать её можно посреди урока, и урок при этом не должен сбиваться |
| Чтение вслух считается по словам, не дословно | Движок склеивает и теряет слова на длинном тексте; порог 75% |
| Чтение записывается по предложению | Целым текстом движок отвечает «ничего не расслышал», а просьбы не обрывать запись он вправе игнорировать |
| Словарь подсказок — по словоформам | Морфологию разбирать нечем, а «plažu — пляж (вин. п.)» полезнее словарной статьи |
| Повтор на слух — отдельный тип, а не флаг | В жалобе видно, какой род задания сломался, и в JSON урока это читается прямо |
| Микрофона нет в аудировании | Продиктовать услышанное — поручить распознавателю ровно то, ради чего задание и есть |
| Тема идёт за системным ночным режимом | Своего переключателя нет: телефон уже умеет решать это сам |
| Не больше 25 карточек за подход повторения | Иначе однажды сессия станет из сотен заданий и её нельзя будет закончить |
| Уроки сгруппированы в разделы | Плоский список перестаёт листаться уже на двадцати уроках |
| Истории вне SRS | Двадцать отрезков в сессии повторения съели бы её целиком |
| Перевод отрезка — награда за прочтение | Показанный заранее, он превращает чтение вслух в чтение по-русски |
| Своя копия прогресса в папку владельца | Auto Backup отстаёт на сутки и молча не работает без Google-аккаунта |
| Восстановление ничего не удаляет | Оно не должно уметь терять данные; при совпадении побеждает файл |
| «Пропустить» — без штрафа | Пропуск значит «не могу сейчас» (шумно, нет микрофона), а не «не знаю»; штраф подталкивал бы бормотать что попало ради зачёта |

## Известные слабые места

- **Промпт проверяющего** (`HaikuChecker.kt`) не откалиброван на реальных ответах. Если вердикты придирчивы или, наоборот, засчитывают ошибки — правится он, а не логика приложения.
- **Промпт правился по двум реальным ошибкам, третьей ждём.** Было: «Hvala lepo» объяснялось как пропуск диакритики (на деле экавица вместо иекавицы), а «Ne radim nedjeljom» отвергалось как падежная ошибка — притом что творительный для регулярного действия верен, и падеж в объяснении был назван неправильно. Оба случая после правки промпта проходят как надо (проверено живыми вызовами 06.09.2026). Следующая жалоба с `verdict_wrong` — снова сюда, а не в логику приложения.
- ~~**Парсинг ответа модели** рассчитывает на чистый JSON.~~ Случилось на устройстве 06.09.2026: модель выдала JSON, следом ``` и «Прошу прощения, переформулирую» — задание ушло в `Blocked` с текстом ошибки парсера на весь экран. Починено ответом, начатым за модель (prefill `{`), и разбором первого сбалансированного объекта.
- **Весь свободный материал — сербский, экавский.** Замерено на 4184 парах Tatoeba: экавских форм 392, иекавских 2. С 06.09.2026 это перестало быть блокирующим: экавица принимается как верный ответ, материал берётся как есть. Где замена очевидна — переводим на иекавицу, остальное остаётся сербским. Подробности в `research/README.md`.
- **Нет экрана статистики.** Сознательно: это ближе к геймификации, чем к инструменту. Но видеть, сколько карточек в работе, может оказаться полезно.
